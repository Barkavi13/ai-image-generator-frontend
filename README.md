# AI Image Generation Platform - Frontend

A modern Flutter-based mobile application that enables users to generate AI-powered images from text prompts. The application provides a clean and interactive user experience with onboarding screens, glassmorphism-inspired UI, image preview, download functionality, and local history management.

## Features

* AI Image Generation using text prompts
* Modern Glassmorphism UI Design
* Splash Screen and Onboarding Flow
* Image Preview and Full-Screen Viewer
* Download Generated Images
* Local History Management using Hive
* Responsive Mobile User Interface
* Integration with FastAPI Backend

## Technology Stack

### Frontend

* Flutter
* Dart

### Local Storage

* Hive

### Networking

* HTTP Package

### Permissions

* Permission Handler
